Public Data Analysis with Stowers Pipelines

This page allows you to have a public dataset from NCBI, EBI, and NIG's collection analyzed using Stowers' own Pipelines.



Instructions

  • Select your lab in the Lab drop-down box, this will let us know where on Stowers' NFS to save your results.
  • Input your Stowers ID in the UserID box, this will allow us to know where to send the results to when finished.
  • Choose your analysis type in the Analysis drop-down box. If you select "Download-Fastqs", links to the downloaded Fastq files will be sent to your email.
  • Select one of the species you would like to use as the reference for alignment from the Reference drop-down box.
  • Enter the SRA / ENA / DDBJ / GEO ids in the Identifiers box, one id per line.
  • Click the "Submit" button to start the analysis.
  • The results will be emailed to you once the analysis is complete.

    • Quick Notes

  • If SRR/ERR/DRR run ids are provided then these will be resolved back to their appropriate SRX/ERX/DRX ids to be able to merge multiple runs from the same experiment. This is conceptually the same as merging multiple libraries sequenced from the same sample.
  • If the run ids provided are of different projects, then analysis will be performed separately for each project, and the results will also be sent out separately.
